# noid against its upstreams: Pi Pocket, rakazo, and pi-web-desktop

Measured on 2026-10-20 at main `3e250d5`. Performance figures are from [performance.md](performance.md).

## Where noid's code comes from

How it was counted: every non-blank line of noid's tracked code files (docs, images, and lockfiles left out, ~130k
lines). A line counts as Pi Pocket's if it survives a diff against the same file at the fork commit `2c6faa4`, or if it
matches a line (25 characters or more) anywhere in Pi Pocket. The same line match was then run against rakazo and
pi-web-desktop. Code rebuilt after an upstream (React/TypeScript there, plain JS here) cannot be found by line
matching, so the "influence in design" row is a file-level estimate from the comments in noid that credit each upstream.

|                      | Pi Pocket         | rakazo                                                                                                        | pi-web-desktop                                                                     | noid's own                                                            |
| -------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Lines copied or kept | **83.2%** (~108k) | **0.2%** (`computer/Dockerfile`)                                                                              | **~0%**                                                                            | **16.6%** (~21.5k)                                                    |
| Influence in design  | The whole engine  | ~5.2k lines rebuilt after it: approvals, auto review, teach, desktop lease, groups, bot mail, computer, faces | ~0.9k lines plus CSS rebuilt after it: tool timeline, Settings, agent files, panes | Bots, the shared computer, routines, terminal, `claude-code` provider |
| License              | MIT (`LICENSE`)   | Apache-2.0 (`computer/LICENSE-rakazo`)                                                                        | –                                                                                  | –                                                                     |

Without `site/` (Pi Pocket's product website, untouched then and removed since): Pi Pocket ~81.5%, noid's own ~18.2%. By area, noid's own code
is about 20% of the server, 14% of the web UI, 26% of the tests, and 74% of `computer/`.
